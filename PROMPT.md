# BT KB & Mouse Pro
A professional Bluetooth Keyboard & Mouse Android app to control any device through Bluetooth HID connection.

Project location: /home/jay/Documents/Scripts/AI/Agent-Zero/deconstruct-apk/new-app

Repository: https://github.com/jnetai-clawbot/BT-KB-Mouse

## Features
- Connection setup for pairing/selecting Bluetooth devices
- Settings page with toggleable device emulation (keyboard, mouse, speakers, mic, video, gamepad, scanner)
- Primary functions: touchpad mouse with drag gestures, keyboard input (3 modes: instant, clipboard, preset history)
- Sensitivity/delay/volume/gain controls with profiles
- Media key support (play/pause, volume, tracks)
- Split view for combined keyboard + mouse
- Dark Material 3 theme
- GitHub Actions CI/CD with consistent keystore for seamless updates
- Persistent error handling throughout
- About section with version, update checker, share button
- Made by jnetai.com
